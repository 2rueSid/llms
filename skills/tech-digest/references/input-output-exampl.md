## Notes

- Titles are sanitized: `Show HN:`, `Launch HN:`, `Ask HN:` prefixes stripped; noise words removed.
- Mail senders normalized from `from` field to display name for section headers.
- `This Week in Rust` mail rendered in its own Mail Subscriptions section (not merged into Rust topic — it's a newsletter, not an HN post).
- Each item has a `[post](ogUrl)` link to the original HN thread.
- GitHub URLs collected from all post fields and mail bodies, deduplicated.
- **Global dedup**: the Freestyle post (id `47663147`) belongs to both Rust and AWS topics — it must be rendered only once (whichever topic comes first). The AWS section would then be empty and omitted entirely.
- **All posts rendered**: every post that passes the off-topic filter is rendered. Mail items are all rendered — no "top 3" truncation.
- **Zero values omitted**: if a post has `comments: 0` or `points: 0`, that field is dropped from the metadata line entirely.
